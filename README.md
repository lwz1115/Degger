# 无人船调试助手 (G12Debugger)

连接遥控器，实时检测无人船运动数据与飞控参数的调试工具。

## 功能

- **无人船调试助手**（主程序 `app/usv_debug.py`）
  - 连接方式：无线调试（自动发现 / 手动地址）、USB 一键连、串口 COM
  - 实时监视：RC 输入通道 + 电机输出通道波形（通道可配置）
  - PID 调试：转向环期望/实际同轴对比 + P/I/D 分项波形
  - 全链路诊断：导航误差 -> 外环 ANG -> 内环 RAT -> 速度环 -> 船体/侧滑 -> 可靠性
  - 自动任务日志：检测到 AUTO 等有效模式开始记录，结束自动保存航段报告
  - 参数实时监视：变化高亮 + 变化日志
  - CSV 运动日志 / 参数快照自动落盘
- **RAT 转向环监视**（`app/rat_p_gui.py`、`app/rat_p_watch.py`）
  - 只读监视转向角速率环，验证调参是否生效
- **离线报告**（`app/rat_report.py`）：分析记录的 CSV，出诊断报告

## 目录结构

```
app\        主程序源码（含配置 json 与图标）
tools\      分析 / 探针 / 验证辅助脚本
Logs\       运行日志与运动记录（自动生成，不入库）
航段记录\    自动任务航段报告（自动生成，不入库）
```

## 快速开始

1. 安装依赖：`pip install pymavlink`
2. 运行：双击 `启动无人船调试助手.bat`（或 `python app/usv_debug.py`）
3. 连接遥控器（无线或 USB），开始实时监视

## 通道配置

在程序「设置」中可配置实时监视的通道：

- **RC 通道**：CH 编号（1-16，逗号分隔，如 `1,3`）
- **电机通道**：SERVO 编号（1-16，逗号分隔，如 `1,2,3,4`）

修改后需「断开」再「连接」生效。

## 运行环境

- Windows
- Python 3.12（64 位）
- pymavlink、tkinter
